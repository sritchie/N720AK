FTA-850 Memory Book Programmer

Read, edit and program the 400-channel memory book of a Yaesu FTA-850L from the browser over USB. No driver, no Windows. Works in Chrome and Edge (Web Serial).

This browser has no Web Serial support. Open this page in Chrome or Edge on a desktop computer. You can still edit and save .dat and CSV files here.

How to use


    
  
  1. Turn the radio off. Connect the supplied USB cable to the DATA jack.
    2. 
  
  2. Hold SQL while turning the radio on until it shows CP Mode.
    3. 
  
  3. Click Read from radio and pick the FTA-850 port. Chrome asks once per site.
    4. 
  
  4. Edit channels and group names, or Import CSV (columns group,frequency,tag). Save a .dat backup first if you like; the file is YCE46-compatible.
    5. 
  
  5. Click Program to radio. Only the changed blocks are written, then read back and verified.
    6. 
  
  6. Power-cycle the radio to leave CP mode.
    7. 




What this writes. Only the memory-book areas: channel slots, group names, the enable/scan bitmaps and the recall copies. Radio settings, GPS setup, weather-channel names, routes and calibration are never touched, so the worst case is a memory book you re-program. The wire protocol and memory layout were reverse-engineered from Yaesu's YCE46 programmer, and the write path has not yet been exercised against a real radio; keep YCE46 in a Windows VM as the fallback until it has.
